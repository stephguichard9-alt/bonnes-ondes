# Bonnes Ondes

Voici une page Web réalisée dans le cadre d’un devoir de HTML/CSS en cours de documentation audiovisuelle.

Pour alimenter un site web nommé Bonnes-Ondes, la page présente une sélection d’instruments de musique (guitares, batteries, claviers)
ainsi qu’une bibliographie musicale.

La bibliographie a été exportée au format HTML depuis Zotero et intégrée à la page
avec conservation des métadonnées COinS.

Le site est publié avec GitHub Pages.
